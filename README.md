# nifragos.github.io

Personal site of Nikolaos Fragos, served by GitHub Pages from `master`.

```
index.html          the whole site: book, about, work, projects, education, contact
assets/site.css     the only stylesheet; colour tokens and fonts match projectariadne.dev
assets/fonts/       Newsreader subsets, copied from the Project Ariadne site
assets/*.jpg        book cover and profile photo
```

No build step, no JavaScript. Preview with `python3 -m http.server` and open http://localhost:8000.
